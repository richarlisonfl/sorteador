# Sorteador de jogos

Página estática em HTML, CSS e JavaScript com uma tabela de equipes e turmas.

## Como usar

Abra `index.html` no navegador ou acesse a página publicada no GitHub Pages. A tabela começa com 6 equipes e 4 turmas por equipe; os dados ficam no array `teams`, no final do arquivo, e podem ser ampliados adicionando equipes ou turmas.

Os botões de sorteio estão presentes na interface, mas a lógica depende da definição das regras dos jogos.
